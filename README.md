# COS 201 – Computer Programming I
## Week 3 Java Programs

This repository contains three beginner-friendly Java console programs:

1. **SimpleCalculator.java** – performs addition, subtraction, multiplication, and division.
2. **AverageCalculator.java** – calculates the sum and average of numbers entered by the user.
3. **ItemCost.java** – calculates the total cost using the item name, quantity, and cost per item.

## Requirements
- Java Development Kit (JDK) installed.
- A terminal or command prompt.

## How to compile
Open a terminal in the folder containing the files and run:

```bash
javac SimpleCalculator.java AverageCalculator.java ItemCost.java
```

## How to run each program

Run the simple calculator:

```bash
java SimpleCalculator
```

Run the average calculator:

```bash
java AverageCalculator
```

Run the item cost calculator:

```bash
java ItemCost
```

## Notes
- Enter numbers when a program requests numeric input.
- The calculator supports `+`, `-`, `*`, and `/`.
- The simple calculator prevents division by zero.
- The average calculator requires at least one number.
- The item cost calculator does not accept negative quantities or costs.
